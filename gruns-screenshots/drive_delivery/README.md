# Grüns (gruns.co) full-site screenshots

Desktop full-page JPEG captures of public pages on https://gruns.co.

## Contents
- `out/` — JPEG screenshots organized by section:
  - `00_home` — homepage
  - `10_products` — product pages
  - `20_collections` — collection pages
  - `30_blogs` — blog posts
  - `40_pages` — Shopify pages / landing pages
  - `50_other` — other public routes
- Each screenshot has a sibling `.json` metadata file (URL, status, bytes, height, timestamp).
- `MANIFEST_FINAL.md` / `manifest_final.json` — audit of target vs captured.
- `urls_exhaustive.txt` — exhaustive public URL list used as the capture target.

## Capture notes
- Viewport: 1440×900, full-page JPEG quality 82
- Max captured page height capped at 14000px
- Cart/checkout/account/admin paths were excluded (robots-disallowed / non-public)
- Overlays (cookie/consent) dismissed when possible
