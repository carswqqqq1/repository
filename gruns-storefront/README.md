# Grüns storefront replica

High-fidelity visual replica of [gruns.co](https://gruns.co) built with Vite + React + TypeScript.

## Run

```bash
npm install
npm run dev
```

## Included

- Homepage sections matching live IA (announcement, hero, press, flavors, value props, benefits, science, buybox, promo, social, final CTA, footer)
- Product routes for Adults / Kids / Shrek variants
- Learn / Rewards / policy / cart / account routes from the live sitemap
- “Try Your Luck” match-3 entrance modal
- Brand fonts (Work Sans, Retail Display) and CDN product imagery captured from the live theme

See `DESIGN_BRIEF.md` for tokens, copy, and route inventory.
